# Café Etrusca — Sitio corporativo

Sitio corporativo de [Café Etrusca](https://cafeetrusca.com): referente de la industria del café en México desde 1995. Café, insumos, accesorios, maquinaria, educación barista y sucursales.

## Stack

- Angular 19 (SSR)
- Bootstrap 5
- TypeScript

## Páginas

| Ruta | Contenido |
| --- | --- |
| `/` | Inicio: hero, productos, recetas, promociones, compromiso, novedades, descargables |
| `/nosotros` | Quiénes somos, misión, visión, valores y marcas (La Fenice, Barista Champ, ChillOut) |

## Desarrollo

```bash
npm install
npm start
```

Abre `http://localhost:4200/`.

```bash
npm run build
```

El build de producción queda en `dist/cafe-etrusca-corporativo/`.

## Assets

Imágenes y video en `public/assets/` (logo, catálogos, mascota Loki, mapa, banners).
